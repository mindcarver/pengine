# 结果与边界

在既有“编辑部卷宗/纸张”工作台中加入账号入口和作品库，不重做创作台。未登录用户只见账户页；登录后延续原有选择人格、创作、进度和阅览路径。

## 关键旅程

### J1 注册并开始创作

1. 访客打开根路径，看到注册表单及切换到登录的链接。
2. 输入用户名和密码，提交时按钮进入忙碌态。
3. 成功后进入创作台，页头显示用户名；冲突或验证错误保留输入并在关联字段说明原因。

### J2 登录、恢复和退出

1. 已注册用户在同一账户页切换至登录。
2. 成功后回到工作台；会话失效时保留当前表单草稿并要求重新登录。
3. 用户从页头打开账户菜单，进入“我的创作”或退出；退出后回到账户页。

### J3 找回自己的创作

1. 已登录用户从页头进入“我的创作”。
2. 列表按最近更新时间展示人格、状态、时间及故事摘要。
3. 选择一个条目进入已有进度/阅览流程；无作品时说明可从创作台开始。

## 界面与导航

| 界面 | 服务目标 | 导航 |
| --- | --- | --- |
| 账户入口 | J1/J2 | 登录与注册为同一页面的互斥表单；不显示业务导航。 |
| 工作台页头 | J1/J2/J3 | 新增账户菜单：用户名、我的创作、退出登录。 |
| 我的创作 | J3 | 返回创作台；条目进入已有创作上下文。 |

## 流程与状态契约

- 表单提交中：禁用本表单重复提交，按钮说明正在处理；切换表单不可丢失各自输入。
- 注册用户名已存在：用户名字段显示错误，不暗示是否已注册之外的账户信息。
- 登录失败：在表单顶端显示统一“用户名或密码不正确”，不标出是哪个字段。
- 会话失效：停止受保护 API 调用，保留本地未提交的创作/意见文本，返回登录页并说明需要重新登录。
- 我的创作加载中：保留页头和返回入口，显示紧凑骨架；空列表与服务失败必须区分。
- 无权访问旧 URL：返回工作台并提示“作品不可用”，不显示“属于其他用户”等信息。

## 交互与内容模式

- 用户名作为账户菜单标签，不作为作品作者的公开署名。
- “我的创作”的故事内容以 `故事：` 摘要呈现，绝不把截断大纲伪装为作品标题。
- 默认焦点在账户页第一个字段；错误后焦点移向第一个无效字段；成功切换时焦点移至工作台主标题或“我的创作”主标题。
- 登录/注册通过文字链接互换；退出不需要二次确认。

## 响应式与无障碍

- 宽屏账户表单位于纸张主体的单一窄列，避免与创作表单竞争；窄屏维持单列，按钮满宽。
- 页头账户菜单在窄屏改为明确的按钮/抽屉，键盘可打开、关闭并将焦点还给触发按钮。
- 每个输入有可见标签；错误用文字和颜色共同表达，`aria-describedby` 关联错误信息；提交状态使用 `aria-live`。
- 作品条目是语义链接或按钮，状态不只依赖颜色；200% 缩放不出现页面横向滚动。

## 视觉方向与系统增量

复用既有暗色编辑部背景、纸张内容面和衬线标题。账户入口只添加一张简洁的“入场登记”纸页；账户菜单为功能性工具，不再增加首页常驻侧栏。作品库使用纵向卷宗条目，信息密度低于创作表单。

## 工程衔接点

### 接口需求

- 账户入口需要注册、登录和当前用户结果，并区分验证、用户名冲突和统一凭据错误。
- 页头需要当前用户名和退出操作。
- 我的创作需要当前用户限定的列表、加载/空/失败状态和进入作品的 creation ID。
- 既有创作端点须能以统一 401/404 支撑会话失效和不可用作品恢复。

### 共享契约引用

`contracts/openapi.json` 负责 auth、current user、作品列表以及现有端点的 401/404 语义；字段和操作名以该契约为准。

## 验收映射

- A1：未登录仅可使用账户入口，任何创作 API 被拒绝。
- A2：注册或登录成功后可进入现有创作台，退出后不可继续访问。
- A3：用户只在“我的创作”看到自己的条目，故事摘要不显示为标题。
- A4：桌面、390 px、键盘和 200% 缩放下账户入口、账户菜单与作品列表均可使用。
