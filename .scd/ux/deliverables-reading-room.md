# 成品阅览室体验契约

# 结果与边界

本切片只重做“已交付作品的五类文稿阅读与一次全量重写入口”。创作投递、运行进度、审核规则、交付内容、初稿/修订稿语义和本地单用户边界保持不变。

当前问题不是配色或间距，而是五种不同信息结构被统一作为一个 `<pre>` 长文本渲染：

- 故事大纲缺少章节目录和当前位置；
- 人物小传缺少人物索引，角色边界只能靠用户扫字识别；
- 人物关系缺少关系主轴与人物入口，不能快速回答“谁和谁、起点、张力、变化”；
- 分集大纲缺少逐集导航和单集边界；
- 正式分集剧本没有复用创作中已有的逐集导航，当前 10 集约 2 万字被拼成一份连续长文；
- 桌面端同时保留作品抽屉、文稿导航和重写表单，正文列被压得过窄；
- 页面进入“读成品”后仍先占用大幅首屏展示区，回到成品的路径过长。

不在本切片中增加导出、在线编辑、批注、搜索、版本比较、关系图自动推断或新的修订次数。

# 关键旅程

参与者：已完成一次创作的本地编剧/编辑。

目标：快速确认交付结构，逐类、逐人物、逐关系或逐集阅读，并在需要时提交唯一一次全量重写意见。

1. 用户从当前作品或“读成品”进入阅览室。
2. 系统恢复上次阅读位置；首次进入默认打开故事大纲顶部。
3. 用户在五类文稿之间切换，并通过当前文稿的二级导航定位内容。
4. 系统在固定位置持续显示作品名、人格、稿件版本和阅读位置，不让用户误认初稿/修订稿。
5. 用户可返回上次位置，或切换上一项/下一项。
6. 用户决定重写时打开“全量重写”面板，阅读不可逆说明、填写意见并提交。
7. 提交成功后保留初稿可读，界面切换到修订运行状态；失败时保留意见并提供重试。

成功反馈：用户能明确说出当前作品、当前稿件版本、当前文稿和当前位置；长篇内容不需要依赖整页滚动来寻找边界。

恢复路径：刷新后恢复作品和最近阅读位置；结构化阅读数据不可用时回退到完整原文，不隐藏内容或伪造结构。

# 界面与导航

## 进入已交付作品后的壳层

- 折叠首页大幅 Hero，仅保留紧凑页头、返回创作台和本地服务状态。
- 当前作品抽屉收敛为页头中的作品切换摘要；V1 只有一个浏览器记忆作品时不长期占据正文左侧。
- 一级导航固定为五类文稿；初稿/修订稿切换与作品身份同层，不与正文目录混排。
- “一次全量重写”改为次要操作按钮，按需打开侧抽屉；未打开时不占用阅读宽度。

## 全局壳层责任

| 全局组件 | 决策 |
| --- | --- |
| Masthead / 服务状态 | 保留，由成品阅览室改为紧凑高度并继续显示本地服务状态 |
| 首页 Hero | 进入成品阅览室后折叠；返回创作台后恢复 |
| 当前作品抽屉 | 进入成品阅览室后收敛到页头作品摘要，不再占据常驻左栏 |
| 创作流程导航 | 保留“读成品”当前位置；不与五类文稿导航混为同一 tablist |
| 页脚 | 无需变更；它不承载阅读操作或状态，只保留现有产品归属说明 |
| Toast / 共享错误提示 | 保留现有容器，新增 presentation 读取失败和降级提示的可访问文案 |

## 每类文稿的二级导航

| 文稿 | 默认入口 | 二级导航 | 正文单位 |
| --- | --- | --- | --- |
| 故事大纲 | 故事核 | 章节目录 | 章节 |
| 人物小传 | 核心人物第一位 | 核心/次要人物索引 | 单个人物 |
| 人物关系 | 主轴一 | 主轴/支撑关系索引 | 单条关系 |
| 分集大纲 | 第 1 集 | 集数列表，显示集名 | 单集大纲 |

人物关系默认使用“关系清单 + 关系详情”，不从自由文本猜测并绘制关系图。只有共享接口提供明确的节点、边和方向后，才可增加关系图视图；图永远不能替代可访问的文字清单。

# 流程与状态契约

- `已交付 + 进入阅览室 -> 恢复最近位置 + 显示正文`。
- `切换文稿 -> 保持各文稿各自最近位置 + 更新标题、目录与可访问名称`。
- `切换初稿/修订稿 -> 尝试恢复该版本位置；不存在则回到该版本故事大纲顶部`。
- `选择人物/关系/集/场 -> 更新正文 + 更新浏览器内阅读位置 + 把焦点移到正文标题`。
- `打开重写 -> 抽屉显示冻结说明和当前未提交意见；正文仍可阅读`。
- `提交中 -> 禁止重复提交 + 保留输入 + 明确正在冻结修改意见`。
- `提交成功 -> 关闭编辑态 + 初稿继续可读 + 导航进入修订运行状态`。
- `验证失败/依赖失败 -> 保留输入 + 将错误关联到意见字段或操作区 + 提供重试`。
- `结构化阅读数据缺失 -> 显示“完整原文”模式 + 不显示空目录 + 不改变交付成功状态`。

加载时保留壳层和上次目录，正文显示骨架；不得先闪现空白成品或旧作品正文。正式交付五类字段全部为空属于接口/数据错误，不是“暂无内容”。

# 交互与内容模式

- 正文使用语义化标题、段落、列表和剧本块，不再以单个 `<pre>` 承担全部层级。
- 保留交付原文，阅读视图只改变呈现，不改写、摘要或补全内容。
- 每个二级导航项同时显示可理解名称，不只显示序号。
- 分集大纲与分集剧本共用同一集数选择逻辑；切换两者时尽量保留当前集数。
- 分集剧本的场景标题、动作描述、角色名和对白需要可扫描区分；不能靠为某一剧本写正则或语言专用关键词实现。
- 人物小传以人物为最小阅读单位；字段标签是否单独呈现由结构化数据决定，缺少可靠字段时完整保留该人物原文。
- 关系详情展示经过验证的关系条目原文；V1 不把双方、方向或张力拆成机器字段，也不从原文推断关系图。
- “上一项/下一项”使用当前二级单位：章节、人物、关系或集，而不是简单滚动一屏。
- 最近阅读位置只保存在浏览器；服务端内容、任务状态与交付仍由现有本地服务负责。

# 响应式与无障碍

- 桌面正文目标宽度 720–840 px；导航和重写操作让位于正文，不能把正文压成当前约 360 px 的窄列。
- 1120 px 以下收紧页边距并优先保留正文宽度；860 px 以下二级目录进入抽屉；620 px 以下使用单列正文。
- 一级和集数导航使用真正的 tab/listbox 语义之一，不能混合；左右键在同一 tablist 内移动，Enter/Space 激活。
- 切换内容后焦点进入新正文标题；关闭目录或重写抽屉后焦点返回触发按钮。
- 当前项不能只靠颜色识别；同时使用位置、边框或文字标记。
- 正文缩放到 200% 时不横向溢出；横向滚动只允许发生在文稿导航条本身。
- 标题层级从阅览室 `h2`、文稿 `h3` 到内容分节顺序递进；完整原文回退也保留可访问名称。
- `prefers-reduced-motion` 下取消平滑滚动；恢复阅读位置直接定位。

# 视觉方向与系统增量

延续现有“编辑部卷宗/纸张”语言，不重建设计系统。只做三项增量：

1. 阅读优先：减少黑色舞台背景和装饰性留白，把纸张正文提升为主要画布。
2. 结构可见：一级文稿、二级目录和正文标题形成稳定的三层层级。
3. 操作退后：重写入口保持可发现但不与日常阅读争夺版面。

纸张纹理可保留，但横线不能穿过标题和控件；长正文的行高、段距与章节间距优先于装饰。人物、关系、分集不使用五套不同视觉主题，只改变导航与内容单位。

# 工程衔接点

## 接口需求

当前运行时 `ContentPackage` 只提供五个自由文本字符串，无法可靠支持人物、关系、集和场次导航。只读展示契约已由 `../designs/deliverable-presentation-read-model.md` 和 canonical `../../contracts/openapi.json` 固化；生产实现必须满足：

- 原始五类交付文本继续作为权威内容，不被展示结构替换；
- 每类文稿可选提供稳定 section id、层级、标题和对应原文片段；
- 人物小传可选提供人物条目；人物关系可选提供关系条目；
- 分集大纲和分集剧本必须提供 episode number、title 与单集原文；剧本可选提供 scene 目录；
- 所有展示结构必须在生成/持久化边界确定或从已有结构化业务记录读取，前端不得用针对具体作品、语言或人格的正则猜测；
- 展示结构缺失、版本不支持或部分损坏时，API 仍返回完整原文并给出可区分的降级状态。

架构已选择独立的同源只读 presentation resource；端点、字段和错误以目标 OpenAPI 为准，存储与迁移职责以功能架构设计为准。

## 共享契约引用

- 现有作品、运行、版本、修订和正式交付语义继续引用 `contracts/openapi.json`。
- 结构化展示契约引用 canonical `contracts/openapi.json`，不存在第二份运行时事实来源。

## 界面与接口映射

| 界面状态或操作 | 契约映射 | 可见行为 |
| --- | --- | --- |
| 进入成功作品 / 切换初稿或修订稿 | `getDeliveryPresentation` + `run_kind` | 加载对应版本，成功后恢复该版本的浏览器内阅读位置 |
| `status: complete` | 五类文稿均为 `mode: structured` | 启用全部适用的二级导航 |
| `status: partial` | 结构化与 source 文稿并存 | 只为 structured 文稿显示二级导航；source 文稿显示“完整原文”标记 |
| `status: source` | 五类文稿均为 `mode: source` | 不显示空目录，五类原文仍可切换和阅读 |
| `creation_not_found` | HTTP 404 | 清除失效的当前作品编号，返回创作台并说明作品不可用 |
| `presentation_not_available` | HTTP 409 | 保留当前作品摘要，关闭成品正文并提示该版本尚无正式交付 |
| 网络或本地服务失败 | 传输/依赖错误 | 保留上一次已显示正文并标记可能陈旧，提供重试；不得切换到另一作品 |

阅读位置、抽屉开关、当前 tab 和键盘焦点属于纯客户端行为，不新增服务端操作。一次全量重写继续使用现有 revision 操作和错误语义。
