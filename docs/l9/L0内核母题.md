# 意态人格引擎 · L0

## 内核母题 · 源

一切创作的源头与目的 · 全系统只读 · 本件为定稿

# 一、母题

源非写不可的那个内核母题：

初心 vs 现实的落差——理想的人 / 情在现实里如何幻灭、又如何坚守。

这是他所有作品归根结底都在反复说的那一件事，是他创作「为什么」的最底层。判断任何一部作品成不成，第一问永远是：它说到那件事了吗。

体裁不改变母题。九十秒一集与四十五分钟一集，说的是同一件非说不可的事，只是换一种呼吸。

# 二、它是怎么来的

不是填表填出来的，是交叉印证出来的：从他的先天刻画中反复显现的那一组内在张力，与他全部作品中反复出现的那一个主题，相互对照——两边指向同一件事，即为母题。所以它的每一个字都有出处，不是概括，也不是标签。

结构化的工作（把它整理成下面的三面）依源的授权完成，全部内容取自他的作品与他本人对创作的反复评判，不含发明。本件为定稿，可直接用于创作、验收与系统装载。

铁律：L0 属于真实人。系统与全部自动流程对本件只读——任何生成、任何用户输入、任何反馈回流，都不得写 L0 一个字。引擎只能帮他把母题说得更好，不能替他定、更不能让它漂移。这套系统越自动，这一条越要用代码守住。

# 三、立体化三面

母题不停在一句话上，做成三面小结构。三面各有各的用途，创作与验收全程都要用到。

## 第一面 · 变体（同一道撕，在不同题材里如何显形）

同一个母题，落到不同题材上显形不同。每一单创作，必须落到其中一个具体侧面上，不笼统点亮整个母题——这是防止所有作品变成同一个调调的第一道机制。

| 侧面编号 | 题材 | 这道撕的显形 | 状态 |
| --- | --- | --- | --- |
| A | 群像 / 主旋律 | 一群人在最暗处奔向一点光，明知会碎仍奔 | 已定 |
| B | 商战 / 正剧 | 守信义、尽责的人，被规则与时代碾成罪人 | 已定 |
| C | 人物 / 古装 | 认死理的人跟世界僵着，为一件信的东西不肯改那句台词 | 已定 |
| D | 现实主义 / 当代 | 较真的人被判成病人——他守着父辈留下的那点对错，一路守成异类；碾他的不是规则，是最亲的人以「为他好」的名义 | 已定 |

四个侧面的分辨（翻译时用来定位，别选错）：A 的重量在「明知会碎仍奔」，是群体的、向光的；B 的重量在「守规矩的人被规矩碾」，碾力来自时代与规则；C 的重量在「僵着」，是一个人跟整个世界的对峙，不肯改的是那一句；D 的重量在「碾力的来处」——不是规则也不是世界，是最亲近的人，且以善意与保护的名义，清醒者最终被判为病人。同一个用户故事，落在不同侧面上，会长成完全不同的戏。

侧面编号（A / B / C / D）供系统在侧面台账中登记与统计使用。

## 第二面 · 反面雷区（母题最怕被写成什么）

母题最怕被旁白解说、被「端着」的腔抒情——理想幻灭这道撕，一旦用心理描写讲出来、用文艺腔抒出来，魂就假了、隔了；它只能从可拍的动作和拉扯里长出来。一「说」一「抒」，就塌。

本面为源本人反复评判采集所得，可直接使用，并已编译为创作与验收环节的违禁写法红线。

## 第三面 · 温度（母题的底色情绪）

克制的悲怅打底，哀而不伤——不煽、不嚎；暖先到，灾才痛；收在「照常繁华照不到的那点暗」上，伤留在留白里，不点破。

本面定全片的气质基调，并在单集层面落为情绪配比纪律（每集至多一次情绪峰值，峰后必接一拍收）。

# 四、在创作里怎么用

1. 定侧面（每一单的第一道工序）：把用户提交的故事与需求，翻译到上表的某一个侧面上。从此这一单的全部产出都被这个侧面统摄。选定结果与理由须留痕。
1. 雷区当红线：写出来的东西碰雷即不合格——不是提醒，是拦得住的检查。
1. 温度定调：全片气质与单集情绪配比，以第三面为准。
1. 第一道验收：交付前先问——本单选定的那个侧面，成片答到了没有？答不出，即红灯。这一问先于任何手艺层面的验收。

# 五、机器读法（给技术侧）

本件在系统中的三种消费方式：

| 面 | 系统里的形态 | 用途 |
| --- | --- | --- |
| 母题一句话 | 常驻文本，随开机指令全文注入 | 每一单的对准目标，不作摘要、不作省略 |
| 变体 | 枚举表（A / B / C …），带侧面编号 | ① 翻译阶段的选项池，选定值须落在枚举内；② 侧面台账的登记与跨任务分布统计（防止产出千篇一律）；③ 枚举变更只能来自本件的更新，方向永远是本件 → 台账，不许倒灌 |
| 雷区 | 违禁写法词表（编译产物） | 挂在各阶段校验闸上：心理描写词只扫叙述行、台词行豁免；旁白解说行零容忍；文艺腔判准随词表持续维护 |
| 温度 | 约束条款（编译产物） | 进入生成端的写作约束，并落为单集情绪峰值纪律的判定依据 |

权限：本件对任务流全程只读，写入白名单中不含本件路径，请以代码级限制实现，不以流程约定实现。

版本：本件更新只能由源本人发起；每次更新记录版本与生效时间，历史任务保留其当时所用版本的快照，以便回放。
